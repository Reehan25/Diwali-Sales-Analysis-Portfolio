# 🪔 Diwali Sales Analysis — Customer & Revenue Insights

## 📌 Project Overview

This project analyzes Diwali sales data using Python to understand customer demographics, purchasing behavior, product performance, and revenue patterns.

The goal is to identify high-value customer segments, top-performing products, and key business insights.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Key Analysis

- Customer demographics and age-group analysis
- Gender-wise sales analysis
- State-wise sales and orders
- Occupation-wise sales analysis
- Product category performance
- Product category and gender analysis
- Revenue and purchase behavior analysis

## 🔍 Key Findings

- The **26–35 age group** generates the highest total sales.
- **Female customers aged 26–35** represent the largest age-gender sales segment.
- **Uttar Pradesh** generates the highest state-level sales.
- Customers working in the **IT Sector** contribute the highest occupation-level sales.
- **Food** is the highest-revenue product category.
- **Food purchased by female customers** represents the largest product-category and gender segment.

1. Download or clone this repository.
2. Open `Diwali_Sales_Analysis_Portfolio.ipynb` in Jupyter Notebook or JupyterLab.
3. Make sure `Diwali Sales Data.csv` is in the same folder.
4. Run the notebook cells from top to bottom.
